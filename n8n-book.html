I’m happy to share that Linux System Automation with n8n, written with Jack Horsky, is now available from Apress.

Linux administration is full of work that repeats: checking that services are up, reading logs, restoring what failed, running backups, creating and removing accounts. Traditionally this is automated with shell scripts and cron jobs. This book takes a different route. It uses n8n, an open-source low-code/no-code automation platform, to build the same automation as visual workflows that are easier to read, share, and extend.

What the book covers

The book is project-based. Each part builds a real workflow, step by step, on a Linux system:

  • Monitoring — keeping watch on system health and services
  • Log review — collecting and checking logs automatically
  • Service recovery — detecting failures and bringing services back
  • Backups — scheduling and verifying them
  • Account management — automating routine user administration

The final part combines these workflows into a single master automation framework, and then takes an honest look at where low-code tools are strong in system administration and where they reach their limits.

Who it is for

  • Linux system administrators who want to automate routine work
  • IT and DevOps engineers evaluating low-code automation
  • Educators designing practical, hands-on labs
  • Developers exploring low-code tools for IT operations

The code is open

The source code that accompanies the book is published in the official Apress repository on GitHub, so you can follow along with the projects and adapt them to your own systems: github.com/Apress/Linux-System-Automation-with-n8n.
